# KungWatch

**ตัวละครบนเดสก์ท็อป แชท Claude Code ละหนึ่งตัว** เปิดแชทไหนก็ได้ตัวละครของแชทนั้นยืนบน taskbar คนละสี ขยับตามที่แชทนั้นกำลังทำอยู่ คลิกตัวไหนก็เด้งไปแท็บของแชทนั้นทันที

## ทำอะไรได้

- **แชทละตัว สีไม่ซ้ำ:** มี 12 สี ใต้เท้ามีป้ายชื่อโฟลเดอร์โปรเจกต์ + context %
- **ทำท่าตามเครื่องมือที่ใช้อยู่:** คิด, เขียนโค้ด, อ่านไฟล์, ค้นหา, ท่องเว็บ, รันคำสั่ง, git, รันเทส, ลงแพ็กเกจ มี sub-agent ทำงานอยู่กี่ตัวก็โผล่ตัวจิ๋วตามจำนวน
- **คลิกตัวละคร = เด้งไปแชทนั้น:** ดึง Windows Terminal ขึ้นมาและ **เลือกแท็บให้ถูกตัว**
- **เตือนตอนควรหันมาดู:**
  - งานเสร็จ (ถ้าทำนานเกิน 30 วิ)
  - ขออนุญาต
  - context ถึง 80% (ได้เวลา `/compact`)
  - แชทเงียบเกิน 5 นาที (อาจค้าง)
  - โควตารอบ 5 ชม. / รายสัปดาห์ ถึง 80%

  ทุกเรื่องเตือนพร้อมกันสามทาง: ฟองข้อความ, notification ของ Windows และเสียงสั้นๆ
- **% โควตาจริงโดยไม่ต้องล็อกอิน:** อ่านจาก `rate_limits` ที่ Claude Code ส่งให้ statusline อยู่แล้ว ไม่ต้อง OAuth
- **แผงสถิติ:** โควตา 5 ชม./รายสัปดาห์ พร้อมเวลารีเซ็ต, token วันนี้/7 วัน, ค่าใช้จ่ายเทียบราคา API, กราฟรายชั่วโมง และรายการแชท
- **เล่นด้วยได้:** ลาก โยน ตกพื้นแล้วเด้ง เดินข้ามจอได้ ตาตามเมาส์ ลูบหัวได้ จั๊กจี้แล้วหัวเราะ
- **ไม่เกะกะ:** ตัวละครซ่อนและเงียบเองตอนดูหนัง เล่นเกม หรือพรีเซนต์เต็มจอ กด `Ctrl+Alt+K` ซ่อนหรือเรียกทุกตัวกลับ มีโหมด **ห้ามรบกวน** ปิดแจ้งเตือนกับเสียง 1 ชม., ถึง 8 โมงเช้า หรือทุกคืน 22:00–08:00 ปิดหน้าต่างเทอร์มินัลทิ้ง ตัวของแชทนั้นหายภายใน 10 วิ
- **ปรับได้ตามชอบ:** เลือกสีให้แต่ละโฟลเดอร์แล้วแอปจำไว้ มีตัวละคร 6 ตัว 4 ขนาด และเลือกได้ว่าจะใช้เมนูภาษาไทยหรืออังกฤษ

## ต้องมีอะไร

- Windows 10/11
- [Node.js](https://nodejs.org) 18 ขึ้นไป
- Claude Code
- การคลิกแล้วเด้งตรงแท็บใช้ได้กับ Windows Terminal ถ้าเป็นเทอร์มินัลอื่นจะเด้งได้แค่หน้าต่าง

## ติดตั้ง

```bash
git clone https://github.com/chenlab789/kung-watch.git
cd kung-watch
node install.js
```

`install.js` จะทำสิ่งเหล่านี้:
- รัน `npm install` (Electron ราว 100 MB)
- สำรอง `~/.claude/settings.json` ไว้ก่อน แล้วค่อยเพิ่ม hook 8 ตัว
- ต่อ statusline bridge ให้ ถ้ามี statusline อยู่แล้ว ของเดิมจะถูกห่อไว้ หน้าตาเหมือนเดิมทุกอย่าง
- สร้าง shortcut บนเดสก์ท็อป

จากนั้นเปิดด้วย `start.vbs` (หรือ shortcut) แล้วรีสตาร์ท Claude Code ถ้าอยากให้เปิดเองตอนเปิดเครื่อง คลิกขวาที่ตัวละคร → **เปิดเองตอนเปิดเครื่อง**

ถอนการติดตั้ง: `node uninstall.js` จะเอา hook ออก คืน statusline เดิม และลบ shortcut กับรายการเปิดตอนบูต

## ทำงานยังไง

```
Claude Code ──hooks──▶ hook.js ──┐
            ──statusline──▶ statusline-bridge.js ──┴─▶ POST 127.0.0.1:7788 ─▶ KungWatch (Electron)
                                                                     หน้าต่างโปร่งใสแชทละหนึ่งบาน
```

- ทุกอย่างอยู่ในเครื่อง ไม่ส่งอะไรออกเน็ต ไม่ต้องมีบัญชี ไม่มี telemetry
- ถ้าแอปไม่ได้เปิดอยู่ hook จะเงียบไปเอง ไม่ทำให้ Claude Code ช้า
- KungWatch ใช้พอร์ต 7788 ถ้ามีโปรแกรมอื่นใช้อยู่ จะขึ้นกล่องบอกแล้วปิดตัว
- token นับจาก log ในเครื่องของ Claude Code (`~/.claude/projects/**/*.jsonl`)
